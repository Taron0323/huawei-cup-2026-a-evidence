# Immutable Formal-Run Workspace v4

`source.sha256` 是正式矩阵启动前的逐文件哈希。每个子运行 manifest 必须与这些哈希一致；发现哈希漂移、缺失批次清单或非完整状态时，整次运行只能作为过期证据。

C 场景每个组合最多 4 次官方评估：先评估同核数 B 最终方案；第二次优先确认轻量 Cache 命中机会；第三次评估轻量最优方案；若前三次均无官方命中，第四次优先确认忙核延迟候选，否则评估容量候选。最终仍按官方 Makespan、额外搬运量选择。

轻量 FIFO 回放对同一张量的每个消费核心按远端生产核心数展开查询；它只用于候选排序，官方 `cache_events` 和 `cache_stats` 仍是正式结果来源。
