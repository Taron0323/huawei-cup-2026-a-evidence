## 目录说明

- `01_官方网页/`：10 个官方页面的原始 HTML 与正文提取版。HTML 保留原始引用，离线阅读优先使用 Markdown；网页正文中的图片另行归档。
- `02_官方附件/`：12 份原始附件，共 11,464,516 字节，含 8 个 PDF、3 个 DOCX、1 个 DOC。
- `03_网页内嵌图片/`：正文直接引用的 4 张图片，包含官方联系方式等二维码。
- `04_附件可检索文本/`：12 份附件文本提取结果。扫描件正文优先查对应官网正文，不将空文本误认成空文件。
- `来源清单.json`：49 条来源记录，含请求网址、最终网址、来源页面、采集时间、大小、SHA-256 和服务器文件名。
- `采集记录/检索覆盖.json`：13 页通知列表及 130 条列表记录的筛选结果。
- `采集记录/通知列表快照/`：检索时的 13 页官方通知列表原始 HTML。
- `采集记录/下载校验报告.json`：附件读取和哈希检查结果。
- `采集记录/collect_public.py`：本次公开资料采集脚本。再次采集应先另存新日期目录，避免覆盖历史快照。
- `采集记录/verify_and_extract.py`：附件验证与文本提取脚本。
- `文件清单.json`：最终归档文件的完整大小和哈希清单；该清单不包含自身。

## 来源与范围

主要来源是[研创网数学建模竞赛官网](https://cpipc.acge.org.cn/cw/hp/4)及其[大赛通知栏目](https://cpipc.acge.org.cn/cw/contestNews/list/4/1)。逐页扫描 13 页列表，归档 2026 年发布的 5 则相关通知，下载它们公开直链的全部附件。发现阶段也检索了 Bing，并查看浙江大学通知以定位官方入口；高校内部通知不作为全国规则。

[2026 开赛公告](https://cpipc.acge.org.cn/cw/contestNews/detail/4/2c90801ca06f016101a0a47e06b77d9b)页面标注发布时间为 2026-09-15，正文落款和格式、AI 附件落款为 2026-09-16；两种日期均按原文保存。

“全部”指本次已发现且可公开下载的当届官方页面及直接附件，不包含尚未发布的赛题、需要队长账号的下载、未来公示结果、往届论文全集、付费培训及各高校内部安排。该范围的缺项与后续节点见 `未开放与未确认内容.md`。

## 校验结果与限制

49 条已归档来源记录的本地大小与 SHA-256 全部一致。8 个 PDF 共 67 页可解析；3 个 DOCX 的 ZIP CRC 和正文 XML 可读取；1 个 DOC 能提取正文并渲染。部分源 PDF 的交叉引用表触发解析器恢复警告，但 Poppler 仍可读取，未重写官方文件。

参赛邀请函 7 页和网评专家通知 1 页为扫描页，文本提取不足，对应官网正文已保存。论文模板在临时目录完成预览，封皮四个标志存在；源 DOC 含制作者本机图片路径字段，已保留原件，不应因更新外部链接而替换官方标志。最终 Word/PDF 仍需在实际编辑环境检查。

本次没有登录账号、报名、支付、上传或执行 MD5 工具。旧 CUMCM 复盘包未修改，其审查结果见上一级 `文件夹审查报告_20260916.md`。
