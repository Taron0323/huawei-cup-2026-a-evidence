# 华为杯2026文件夹审查报告

审查日期：2026-09-16。审查对象：本轮开始时目录中唯一的 `华为杯中国研究生数学建模竞赛_流程复盘包_20260913/`，以及随后检索到的2026官方规则用于交叉核对。原包未修改。

## 发现

### R1 / P1：交付提示词仍强制采用国赛版式

位置：`提示词/17_delivery.md:5`、`提示词/07_outline.md:7`、`模板/latex/README.md:45`。前者明确写“电子版不得含承诺书和编号页，无目录；摘要单页”，模板说明写当前电子版无身份页、正文30页限制。

触发：按照顶层《提示词使用说明》调用交付或论文框架阶段。总说明虽要求核对当年规则，但具体执行指令仍与2026华为杯要求冲突。

证据：2026开赛公告第四部分要求首页封皮不可删除，封皮包含团队信息，4个logo不能替换，其他页面匿名，摘要不超过两页。附件2未给出旧国赛的正文30页上限。

影响：可能删除必需封皮，或不必要地压缩摘要与正文。修复：将华为杯执行提示词绑定本届原文，旧国赛版式留在历史参考中。验收：使用官方封皮、摘要规则、字体、页码和分阶段上传节点逐项核对实际论文。状态：OPEN，官方依据已下载。

### R2 / P1：AI披露模板遗漏本届的具体标注位置和字段

位置：`提示词/17_delivery.md:7`、`模板/ai/README.md:9`、`本次项目证据参考/数学建模-AI全流程工作法-GPT6-Astra-Max-Ultra版.md:477`。

证据：原执行路径以“参考文献前统一声明 + AI工具使用详情.pdf”为中心；2026华为杯附件4第4条要求在数据分析结果前导或后面标注AI输出来源，第5条要求在程序前面添加辅助编程注释，包含工具名称、版本/型号、开发机构/公司和版本颁布日期。旧AI日志的15列也没有独立的开发机构和版本发布日期字段。

影响：即使完整填写旧模板，也不能据此判定本届披露要求已覆盖。修复：保留真实使用记录，补齐本届条款对应的字段和正文/代码位置检查；旧统一详情可作为内部记录，但不能替代具体标注。验收：逐项映射附件4第3至6条。状态：OPEN。

### R3 / P1：LaTeX和Word模板关键文件未随包交付

位置：`模板/latex/main.tex:7`、`模板/latex/demo.tex:138`、`模板/word/README.md:3`。

证据：main.tex引用10个sections文件，当前包中均不存在；demo.tex还依赖缺失的figures/decay.pdf和make_figures.py。Word目录只有README，没有说明中宣称的model-template.docx。README中列出的预览文件也没有随包提供。

实际复现：使用本机XeLaTeX/latexmk编译main.tex，latexmk退出码12，报错 `File 'sections/00_abstract.tex' not found`，未生成PDF。编译输出仅写入临时目录，未向原包补文件。

影响：按“可直接填写骨架”或“Word兜底”说明无法开工。修复：补齐模板依赖并在全新解压目录编译；本届排版应以新下载的官方Word原件为依据，不机械恢复国赛模板。状态：OPEN。本次已额外下载2026官方DOC，但没有把它冒充旧模板修复。

### R4 / P2：总控入口和多个阶段依赖未包含的脚本与旧路径

位置：`提示词/00_controller.md:3`及`:5`、`提示词/README.md:5`、`提示词/20_preflight.md:3`、`模板/ai/README.md:17`。
