# 正式支撑材料暂存区

尚无正式赛题，因此当前没有正式代码、结果或支撑数据。不要把practice或参考论文放入本目录。

开赛公告规定：赛题明确要求上传附件时按题目提供；即使无明确要求，队伍认为支撑材料有助于理解成果且在论文注明，也可在附件窗口提交。没有统一要求把所有原始数据、整个工作区或整段聊天全部上传。选择实际必要且有权提供的文件。

建议实际交付结构：code放运行入口及依赖，results放正文所引用的完整计算表，data仅放必要且允许提供的数据。REPRODUCE.md写明运行顺序与输出。MANIFEST.csv逐文件记录角色、对应问题、论文位置及SHA-256。外层压缩包名按题号+队号，内部名称采用匿名的描述性名称。

论文中“完整结果见支撑材料”必须能找到确切文件；附录的材料表从同一清单填写。若使用AI辅助编程，代码前须有本届要求的四字段；若题面要求AI输入和处理策略，按真实记录加入，不以统一声明替代。

本区不得包含参考PDF、历史材料、.venv、缓存、临时日志中的私人路径、账号凭据、学校/姓名/学号等身份信息。需要日志时导出匿名、必要的运行记录。

先执行 `.venv/bin/python tools/check_submission.py`，它检查论文占位词、已知身份信息与支撑清单；输出不代表人工通过。清单为空会明确显示NOT_PREPARED。

附件上传窗口暂为9月29日08:00至30日24:00，实际以后续公告及系统为准。开赛公告给出.rar示例及50M限制，9月21日提醒的“附件”又给出.pdf示例；正式打包前核对实际入口要求。本机尚无RAR创建工具，也未取得正式赛题，未生成假附件。当前准备ZIP仅作备份。
