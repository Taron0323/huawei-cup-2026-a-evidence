## 对当前 A 题图的应用边界

- 主速度比曲线：每核的 100 图逐图比值先计算，再给均值、中位数和描述性的 10%–90% 分位带；A 单核正式点为 1，A 的优化后单核放在诊断图表。若另给 bootstrap 均值区间，须标明 100 图重采样方法与区间含义，不能把分位带标成均值的 95% 置信区间。
- 候选比较柱图：标题写“首个成功官方候选与最终选中候选”，条顶给确切比例/数量，不写“机制移除消融”。配色和纹理共同区分 A/B/C，黑白打印仍可识别。
- Cache 图：B 固定计划在两硬件下的效果、Cache 下选中方案相对 B 计划的变化及最终 B/C 比较分开画；逐图的三个比值满足乘积关系，但三个算术均值不应相乘。命中率注明按字节汇总还是逐图平均。
- 敏感性图：`n=6` 的代表图逐例点、固定计划与重优化重合情况、容量/带宽扰动方向应直接可见。6 图的区间带只能作描述性离散展示，不宜无设计依据地写成总体推断的 95% 置信区间；24 组重优化均未换最终计划。
- 放大框或拐点标注只选择数值和真实事件支持的位置，例如有具体案例的核数退化、Cache 参数阈值或调度依赖；注明图号、核数、cycles 或 bytes。不要为美观创造不存在的“拐点”。
- 图后紧跟定量解释：给比较方向、样本量、单位、异常例和与模型约束的联系。流程图只表现实际实现的有限候选与官方评估链，不把未实施的 FIFO 回放、分散候选或保底机制画为已完成。
