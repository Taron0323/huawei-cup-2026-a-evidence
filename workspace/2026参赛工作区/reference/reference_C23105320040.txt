                  摘       要
  大规模创新类竞赛参数作品评审受评委的主观因素影响，探究新的创新类竞赛评审
方案对于当前大规模创新类竞赛具有重要意义。
  本文主要研究了多种评分优化方案，基于优化评分模型的探究创新类竞赛的评审方
案。对标准分改进建立改进梅西打分法评审模型，采用熵权法结合投影寻踪法建立组合
权重 TOPSIS 综合评价模型，基于高斯混合聚类分析建立逻辑回归模型并通过偏相关性
分析对模型进行验证，为实际大规模创新类竞赛评审工作提供了理论指导。
  针对问题一，建立最优“交叉分发”方案数学模型。首先根据题目所给数据将 125
位专家平均划分成 5 个评阅大组，再将每个评阅大组内 25 位专家均分成 5 个评阅小组，
每个评阅小组 5 位专家，并规定每个作品由 5 位专家进行打分，且每位专家对同一份作
品最多评阅一次。然后给出交集和测度的定义，并使得每个小组内和每个小组间互有交
集。最终得出当小组内任意两位专家评阅的作品交集率为三分之一时，取得局部最优，
的部分分配结果见表 1。
  针对问题二，建立基于改进梅西打分法的标准分计算模型。首先为研究每位专家、
每份作品原始成绩和调整后成绩的分布特点，分别对参与第二轮评审专家和未参与第二
轮评审专家进行描述性统计。接着基于改进梅西打分法建立作品评分的数学模型，基于
组合权重法建立 TOPSIS 综合评价模型，基于数据标准化修正的熵权法与改进遗传算法
的投影寻踪法判断确定各指标权重。然后计算 TOPSIS 得分判断不同方案的优劣性，并
建立一次改进标准分计算模型，求解得到的具体公式见式(34)和基于一等奖标准分与复
议分的二次改进标准分计算模型。最后利用切尔诺贝利灾难优化器对新的标准分公式进
行求解，得到的公式见式(37)，并对问题二结果进行检验。检验结果见图 8。

                  一、问题重述

1.1 问题背景
  创新类竞赛需要评审专家根据命题人提出的评审建议进行独立评审。对同一份作品，
不同评委的评分可能存在较大差异。在竞赛规模大，评委的人数众多的情况下，极差大
的问题更为突出。为确保大规模创新类竞赛评审方案的公正性、公平性和科学性，通常
可以利用对每位评审专家的评分进行标准化；去掉同一份作品得分中的最高分、最低分，
再将剩余评分相加，最后依总分排序；对初选入围的作品组织二次评审等方式。
  在大规模创新类竞赛中，增加评审每份作品的专家人数有利于评审工作的公正、公
平。在不影响获奖等级的前提下，为了适应评审专家人数较少的现状，不少竞赛采用两
阶段评审办法。附件给出模拟大规模创新类竞赛的数据。
1.2 问题描述
   问题一: 在各个评审阶段，通常将作品随机分发并由多位评委独立评审。为了增加
不同评审专家所给成绩之间的可比性，应增加不同专家评审的作品集合有一些交集。针
对 3000 支参赛队和 125 位评审专家，每份作品由 5 位专家评审的情况，建立数学模型
确定最优的“交叉分发”方案，并讨论该方案的相关指标和实施细节。
   问题二: 选择两种或两种以上现有或自己设计的评审方案和题目附件数据，对每位
专家、每份作品原始成绩、调整之后成绩进行排序，针对大规模创新类竞赛的评审，设
计新的标准分计算模型，利用附件数据，改进标准分计算模型。
   问题三: 同一份作品的几位专家给出的成绩会有较大的极差。请根据题目所给的模
拟数据，讨论两阶段的成绩整体的变化和两阶段极差整体的变化，分析两阶段评审方案
相比不分阶段评审方案的优劣。针对附件所给数据，建立“极差”模型，并给出第一评
审阶段程序化处理非高且非低分段作品的“大极差”的办法。
   问题四: 为创新类竞赛，建立一个完整的评审模型，并针对所给的数据给出改进的
具体建议和策略。

                  二、思路分析

2.1 问题一的思路分析
  问题一要求建立模型确定最优的“交叉分发”方案。为承接后续问题，假设每个参
数作品由 5 位专家打分，且每位评审专家对同一作品最多评阅一次。由于 125 位专家数
量较为庞大，为便于计算，首先将 125 位专家分成 5 个评阅大组，每组 25 位专家，再
分别将每个评阅大组继划分成 5 个评阅小组，即 125 位专家分为 25 个评阅小组。其次
分别对交集和测度给出相应的定义，确定整个分配方案的综合可比性指标，并确保每个
大组与小组之间都有相应的交集。最终求得最优的“交叉分发”方案。
2.2 问题二的思路分析
  问题二要求对标准分计算模型进行改进，本文采用梅西打分法作为自定义评审方案。
首先分别对第一轮 97 位专家和第二轮 16 位专家评阅的作品进行描述性统计。再利用题
干中的方案一，方案二以及方案四，统计每位专家评阅的作品样本量，分析最大值，最
小值，平均值，中位数，方差，标准差，偏度，峰度并判断这些数据是否服从正态分布，
分析原始数据的分布情况，并选取四个指标变量评委打分之间的差异度，重合度，平均
乱序度，最大乱序度。然后采用熵权法+投影寻踪法每个确定变量的权重，并通过带有
组合权重的 TOPSIS 评判四种评审方案的优劣性，进行打分排名；针对大规模创新类竞

2.3 问题三的思路分析
  针对问题三的相关要求，首先对两阶段作品的标准分均分，以及两阶段作品得分的
极差进行差异性分析，并对两组数据取得的一等奖到三等奖不同成绩和极差进行 Apriori
算法分析，分析整体变化情况。接着以问题二中给出的改进梅西打分法为基准，对分别
对第一轮作品标准均分和第二轮作品的标准均分进行排名，并对排名进行正态性检验以
及斯皮尔曼相关系数分析，分析不同排名方案对基准的影响以及创新性和极差大小的联
系。然后通过对进入复议后作品得分的极差进行分析，建立逻辑回归模型求出作品进入
二轮评审的概率，选取第一轮标准均分以及标准极差，进行高斯混合聚类以及灵敏度分
析，并利用决策树量化作品评级标准。最后对选取的 6 个服从正态分布的指标进行斯皮

重共线性检验（VIF）对指标进行筛选，对模型进行验证，得到修正公式，并得到修正
公式，运用 Sobol 灵敏度分析探究各指标对因变量的重要程度。
2.4 问题四的思路分析
  问题四要求给出一个完整的评审模型，首先利用 5 名专家对作品打分的情况建立的

3.2 基本假设
                     6
  为了简化问题，我们做出以下基本假设，并且每一个假设都是合理的。
 假设 1: 在问题一中，125 位评委都参与评审，且每个评委评阅的作品数量相同。
  理由: 根据题干可知，增加评审每份作品的专家人数，显然有利于评审工作的公正、
公平，为提高公平率且方便计算，故假设所有评委都参与评审。
 假设 2: 所有专家对相同的作品最多评审一次。
  理由: 在实际情况中，一个作品第一次评审应由 5 位不同的评审专家进行打分，一
个作品在初审被打 5 次分，而不会出现同一作品被一个专家进行多次评分。
 假设 4: 每个评委阅卷公平公正，不存在误判情况。
  理由: 不考虑评委误判的情况，即由于错误判断，将好的作品评了最低分或将差的
作品评了最高分，论文客观水平和评委评分服从正态分布。
 假设 5: 本文研究中使用的数据是准确的。
  理由: 我们假设附件中的数据，与实际情况没有出现明显的测量偏差而被认为是虚
假的，因此可利用这组数据建立优化模型，为大规模创赛评审方案提供帮助。

                四、模型的准备

4.1 文献综述
  根据题目所给信息及查阅相关参考文献，可以得到如下信息：
 改进梅西打分法，由分差方程建立线性方程组，方程组的解受到毎个方程的制约，
  依据Ｔ分数从整体上对每个作品进行的重新评价，优化了排名结果影响[1]；
 切尔诺贝利灾难优化器(CDO)，即 CDO 模拟了核爆炸后附着人体时的核辐射过程。
  核爆炸和附着人类的主要步骤是在其中γ粒子，β粒子和α粒子都参与了这个过程[2]；
 高斯混合聚类，由于传统聚类方法不能识别在轻微倾斜的标签设置下从哪个样本集
  群。从聚类联合学习的角度出发，高斯混合聚类方法（GMCFL）能有效地聚合集群

6.3.1 基于组合权重法的 TOPSIS 模型建立

  组合权重法可以结合投影寻踪和熵权法来确定指标的权重。投影寻踪法通过考虑投
影特征值的标准差、方差、熵以及局部密度等指标函数来进行权重计算，而熵权法则是
根据比较指标信息熵来确定权重[2]。
  在组合权重法中，首先使用投影寻踪法对指标进行权重计算。投影寻踪法通过最大
化或最小化投影指标的非线性度量来确定权重。这些非线性度量包括标准差、方差、熵
以及局部密度等指标函数。通过选择适当的非线性度量函数，并使用优化算法迭代更新
权重向量，最终得到一组权重。
  接下来，采用熵权法对上述得到的权重进行进一步的调整，熵权法考虑了指标信息

             十、模型的评价与总结

9.1 模型的优点
  （1）本文运用改进梅西打分法，具有较强的客观性和普适性；
  （2）各个数学模型之间联系紧密，模型整体性较强，逻辑较为清晰，如问题四的
  完整评审模型就是基于问题一、问题二和问题三的模型得出的；
  （3）模型的灵敏度分析表明了模型在不同参数组合下的有效性，证明了模型的鲁
  棒性，并且文章可视化效果良好。
9.2 可能的改进
  （1）本文对于间接测度的定义仅满足于本题条件的情况，在实际情况中可能会出
  现一些偏差，缺乏较强的普适性。
  （2）梅西打分法需要满足评分服从正态分布情况，竞赛型评分不一定都服从正态
  分布。对于非正态分布的情况，一是寻找有效的方法，将评分调整为服从正态分布；
  二是对本文方法进行改进，使其也能有效适用于评分不服从正态分布的情况。
9.3 模型的推广
  （1）本文主要建立了大规模创新类竞赛评审打分模型，有较高的客观性，不仅适
  用于大规模创新类竞赛，也适用于非客观题的评价、科研成果评价、学科及学校评
  估等其它带有主观性评分的项目，如推广到各大高校研究生的毕业论文评审工作中。

def compute_features(row):
   values = row.dropna().values[1:]   # 排除第一列标题并去除空值
   n = len(values)
   if n == 0:   # 防止有些行只有标题没有数据
       return [0] * 13


   mean = np.mean(values)
   std_dev = np.std(values)
   cv = variation(values)    # 计算变异系数
   max_value = np.max(values)
   min_value = np.min(values)
   median = np.median(values)
   variance = np.var(values)
   kurt = kurtosis(values)
   skewness = skew(values)


   _, p_value = normaltest(values)    # 正态性检验


   distribution_type = 'Normal' if p_value > 0.05 else 'Non-normal'
