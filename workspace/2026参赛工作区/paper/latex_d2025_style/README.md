# 2025 D题原稿风格 LaTeX 模板

本目录依据用户提供的《基于多源数据融合的低空湍流监测与航路优化》110页PDF制作，供华为杯2026赛前写作准备。状态为 `PREPARATION`。正文已有实质性示范段落、数学公式、图表和三问的完整章节，结果字段保留为“待计算”或“【……】”。

## 四个入口

| 入口 | 输出 | 用途 |
| --- | --- | --- |
| `main-reference.tex` | `output/main-reference.pdf` | 可编辑原稿风格版，使用原稿的中文/西文字体组合、行距、章节树、24个编号图位与16个编号表位 |
| `main-2026.tex` | `output/main-2026.pdf` | 2026格式版，由构建脚本拼接官方封面、统一摘要与LaTeX正文，启用结果附近的AI标注和使用说明 |
| `models.tex` | `output/models.pdf` | 独立的25类常见模型备选，含段落、公式、适用条件和检验方法 |
| `facsimile.tex` | `output/facsimile.pdf` | 110页原样影印入口，整页引用原PDF，保留原稿页面；其中正文不能作为LaTeX文字编辑 |

`facsimile.tex` 用于原样页面对照，`main-reference.tex` 才是可编辑写作模板。两者的性质不能混淆。可编辑版使用重新写作的填充正文与示意图，分页和字数随内容变化，不是原110页的逐字源代码恢复。原PDF第64至110页为代码附件，可编辑模板改为可替换的程序排版和支撑清单。

原稿主章和小节顺序保留，包括原稿中8.3与8.5同名的“问题三计算结果展示”；标题错字及损坏的8.3.4标题已修复。为满足每个主章都有图表，增加的图表使用 `S` 编号，不干扰原24图、16表的编号。

## 直接编译

在本目录执行，依赖Python 3、`pypdf`、XeLaTeX，以及CTeX、Fandol、TeX Gyre、amsmath、booktabs、tabularx、caption、algorithm、algorithmic、fancyvrb、eso-pic、hyperref等常用宏包。

```bash
python3 -m pip install -r requirements.txt
python3 build.py
```

当前工作区可从根目录执行：

```bash
.venv/bin/python paper/latex_d2025_style/build.py
```

仅编译一版：`python3 build.py --only main-reference`。图像已经随包提供，编译无需重新生成。需要修改示意图时，安装NumPy、Matplotlib并运行 `python3 build.py --figures`。所有图的生成公式、配色和布局在 `generate_figures.py` 中。

本机原稿封面使用Microsoft Word附带的STXinwei字体；其他机器缺少该字体时退回楷体。2026版正文要求可用的宋体/黑体；脚本优先检测本机Word字体路径，否则使用系统字体名称。字体文件不随包分发。若缺少官方要求字体，应先安装合法字体，不能将字体回退误记为已符合2026要求。

## 从哪里改

- `sections/01` 至 `09`：九个主章，每章已有正文、图表；公式和图表交叉引用自动更新。
- `sections/abstract-prose.tex`：原稿风格版摘要。
- `frontmatter.docx`：2026官方封面和摘要的可编辑工作副本，需填写真实队伍信息，保持四个标识及统一格式。
- `frontmatter.pdf`：上一个Word文件的导出结果，目前为封面1页、摘要2页。修改Word后重新导出到同一文件，再执行构建脚本。
- `sections/11-support.tex`：正文附件索引、代码排版、程序前AI说明。
- `sections/12-ai.tex`：2026版AI汇总说明。
- `preamble.tex`：字体、标题、编号、图表样式及AI四字段；实际不同工具的标注可在对应位置分别填写。
- `docs/逐章写作与语言复刻指南.md`：每章与每个方法小节应写什么。
- `docs/复刻对照与技术修正.md`：测量依据、原稿与两版模板的对应及差异。
- `docs/执行提示词.md`：本轮完整可复用任务提示词，所列模板制作与验证已在本目录执行。
- `sources/`：用户原PDF、网页题面转载、检索来源、版式测量及2026相关规则原件。
- `qa/`：结构覆盖、编译、渲染和影印对照记录。

## 2026规则入口

2026版使用官方Word封面和统一摘要，摘要从1开始编号且不超过2页，正文另页开始并续接页码，无页眉。正文采用小四宋体、一级标题四号黑体居中和单倍行距。原稿风格版使用Fandol宋体及更大的行间距，供样式学习。

AI数据分析结果旁、AI辅助程序前均预留名称、版本/型号、开发机构和版本发布日期四字段。独立汇总说明是本地整理方式，不能替代就近标注。题面要求时再提交AI输入与后处理记录。

支撑材料须根据真实题目和正文承诺整理，50M上限按已有官方规则核对。当前公告中附件扩展名存在 `.rar` 与 `.pdf` 示例差异，需结合实际系统及后续说明确认。本目录的ZIP是模板交付包，不是比赛附件。

## 证据范围

2025 D题的任务描述已通过公开网页检索取得，归档来源为博客园题面转载，未取得官方原始题面PDF和完整数据附件。题目名称、三问、100m/50m/2km网格及预报时段可在转载中核对，公式图片等未通过转载文本恢复的部分不视为完整题面。

图表中的曲线、分布、点位与柱状数值由固定随机种子或指定函数生成，仅为排版示意。原稿中的RMSE、识别率、航路收益和回归系数没有移作本项目结果。正式论文需替换全部示意图、占位字段、拟交付模块名和参考来源说明。

## 已完成的检查

最终输出为原稿风格版44页、2026版39页、模型备选8页、影印版110页。73个标题全部对应，九个主章均含实质性中文段落、图和表，32张示意图的矢量PDF与PNG随包提供。

原稿风格版的正文左右边界、字体和19.87pt行距已与原PDF测量对照。110页影印版在PDFium 72dpi下逐页像素一致；原PDF另保持原字节。两种可编辑版的排版内容不同，分页并非原稿110页。详细检查记录见`qa/validation.json`、`qa/layout-measurements.json`与`docs/最终验证报告.md`。

新电脑复跑完整视觉检查另需安装`pdfplumber`、`pypdfium2`、`numpy`、`Pillow`，执行`python3 verify.py`；常规编译只需前述构建依赖。交付ZIP的CRC、逐文件SHA-256及同机新目录重编译结果记录在ZIP相邻的`.verification.json`中。
