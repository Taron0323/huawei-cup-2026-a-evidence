# 本地环境与换机

2026-09-24实验准备复核：Apple M4 Pro、14逻辑CPU、48GiB内存，Python 3.12.10。项目虚拟环境原先继承的pandas 3.0.5超出requirements.txt范围，现已在项目.venv内安装pandas 2.3.3及pytz；系统pandas未改。requirements-lock.txt补齐pandas、psutil及相关时区依赖。全部8项项目依赖满足约束，pip check通过，SciPy整数规划、pandas汇总和Matplotlib内存渲染通过。证据见review/experiment_preparation_20260924/environment_checks.json。这些是工具准备检查，没有运行A题新实验。

当前机器：macOS，本项目.venv基于Python3.12，复用系统已安装的NumPy/SciPy/Matplotlib，并在项目虚拟环境安装pypdf、python-docx及lxml。未修改系统Python包。准确版本见review/environment.json及requirements-lock.txt。

新电脑建议使用独立环境：python3 -m venv .venv，再执行.venv/bin/python -m pip install -r requirements-lock.txt。若平台不提供对应版本轮子，可用requirements.txt的兼容范围安装后重新执行演练、模板与检查；不能直接继承本机验证结论。

系统工具：XeLaTeX和latexmk用于中文论文与演练报告；Poppler的pdftotext、pdftoppm用于抽取和逐页渲染；LibreOffice或Microsoft Word用于官方DOC/DOCX导出。字体需要真实宋体SimSun和黑体SimHei。本机build_paper.py从已安装Microsoft Word字体目录读取，其他平台使用已合法安装的同名字体。准备包不分发商业字体。

本机RAR创建程序未安装，正式附件的扩展名还需核对具体题面与系统。.zip备份不冒充.rar。指定MD5工具尚待队长从比赛系统获取；workspace.py的标准MD5只是独立校验。

例行命令从工作区根目录运行：

```bash
.venv/bin/python tools/workspace.py env
.venv/bin/python tools/workspace.py check
.venv/bin/python tools/test_workflow.py
.venv/bin/python practice/transport/run.py --run-id your-new-run
.venv/bin/python tools/build_paper.py latex
.venv/bin/python tools/check_submission.py
```

Word渲染需使用当前电脑的办公软件，tools/fonts.conf仅用于本机LibreOffice字体发现，不要求其他系统照搬macOS目录。所有核验日志保留实际环境信息；同机解压复跑不等于已通过第二台电脑验证。
