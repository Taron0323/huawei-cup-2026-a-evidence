# AI使用记录与标注

本届依据为官方附件4第3至6条。数据分析在结果附近标注；程序在代码之前标注。统一AI使用记录不能代替这两处标注。

数据分析标注模板：
> 本段数据分析参考了人工智能工具【名称】的输出；版本/型号【真实值】，开发机构/公司【真实值】，版本发布日期【真实日期】。采用内容为【具体内容】，经【实际核验方法】核验，由本队整理表述。

程序顶部注释模板：
```python
# 本程序及代码是在人工智能工具辅助下完成的。
# 工具名称：待核验；版本/型号：待核验；
# 开发机构/公司：待核验；版本发布日期：待核验。
# 采用内容、人工修改及验证证据：填写实际记录路径。
```

这些是待填模板，不可带占位词直接提交。模型显示名称、开发机构与发布日期须有界面/官方来源证据，不从猜测或模型自述填发布日期。当前准备由Codex辅助，开发机构OpenAI；具体模型版本及发布日期尚无本项目独立来源记录，因此标为待核验。

evidence/ai_usage.csv用于正式阶段，包含developer、version_release_date、版本证据、输入、输出、处理策略、结果标注位置、代码标注位置、验证和人工复核等字段。prep/ai_preparation.json只记录本次准备，不能冒充正式阶段已经完整披露。

对模型公式优先保存推导与可核查文献；引用书籍写页码，网页写访问日期。无法确认来源的AI模型公式不能靠填写一条工具信息就认定可接受。赛题若要求提交完整输入与后处理策略，保存相关记录并去除无关私人信息。
