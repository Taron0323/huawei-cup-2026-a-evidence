题 目：   __________WLAN 组网中网络吞吐量建模___________

           摘 要：

  无线局域网（WLAN）在现代通信中具有重要作用，而信道接入机制对网络的整体
吞吐量有显著影响。本文针对三个关键问题进行系统的数据预处理与模型优化，探讨在
高密度部署场景下影响系统吞吐的多种因素，旨在提升WLAN 的整体性能。
  在对问题一的分析中，数据预处理是确保建模准确性的基础。我们对实际WLAN 网
络的训练数据集进行了详细的清洗，包括异常值处理、缺失值填补和特征标准化等步
骤。具体而言，数据集被分为2AP 和3AP 系统，以便分别建模，确保每组数据的特征能
够被准确捕捉。通过随机森林回归模型的分析，我们得到了特征影响强弱排序，发现AP
与AP 之间的RSSI 对发送机会的影响最大，2AP 系统中达到87.96%，3AP 系统下达到
74.94%。其余影响因子强弱顺序依次：AP 和STA 间的RSSI、协议类型、网络拓扑、信
号功率、NAV 门限值、BSS 编号。
  在对问题二的分析中，我们重点分析信噪干扰比（SINR）与传输方式之间的关系，以
预测在不同条件下AP 的物理传输速率（PHY Rate）。我们发现，除了样本本身的特征数
据，样本的SINR 还与同一次实验的其他样本有关，因此在处理数据时，同时考虑了多行
之间相互的影响。通过数据清洗和异常值检测，我们提高了数据的稳健性，并使用Akima
插值拟合算法对RSSI 测量值进行了统一处理，使其数量达到540。我们选用的残差连接优
化后的CNN 模型预测(MCS,NSS)的验证集，构建的模型达到了86.73%的准确率。
  在对问题三的分析中，我们综合考虑了不同AP 之间的干扰及丢包情况，构建了基于
CNN 的统一系统吞吐量预测模型，利用实测数据中的（MCS, NSS）组合作为输入特征。
模型通过一维卷积进行特征提取，池化层减少特征维度，最终通过全连接层实现吞吐量
的预测，并采用Adam 优化器进行模型训练。在干扰情况下，理论吞吐量与仿真结果的误
差控制在5%以内，进一步验证了RTS/CTS 机制在提升系统吞吐方面的有效性。我们对
训练完成的预测模型，通过累积分布函数（CDF）进行模型精度的评估，模型在2AP 和
3AP 系统中验证准确率超95%，体现出该预测模型的优异性能和良好的泛化能力。
  综上所述，本文通过系统的数据预处理与模型优化，成功分析了WLAN 网络中多因
素对吞吐量的影响，提出的解决方案为进一步提升WLAN 性能提供了科学依据。研究结
果对未来无线网络优化和新技术的应用具有重要的指导意义。
关键词：无线网络吞吐量；信道接入机制；随机森林回归；Akima 插值拟合算法；卷

积神经网络；累积分布函数

              一、问题重述



1.1 问题背景


  无线局域网（WLAN）作为现代通信的核心，广泛应用于办公、教育和医疗等领域。
然而，在高密度部署场景下，节点数量激增和小区覆盖重叠，导致干扰和碰撞加剧，实际
带宽和数据传输速率显著下降。因此，准确预测吞吐量对于提升WLAN 系统的稳定性和性
能至关重要。
  近年来，随着机器学习技术的发展，该技术在吞吐量预测中的应用逐渐增多。通过提
取信道带宽、业务流量、发射功率、信道接入机制等特征，结合RSSI、信干噪比（SINR）
以及节点动态位置等信息，可以使用机器学习模型来预测系统吞吐量。目前的吞吐量预测
方法大多基于仿真数据，但仿真结果通常无法全面反映实际环境中的信道条件、干扰动态
以及复杂的业务流量，这导致了预测模型的精度有限，难以在真实部署中有效应用。
  为应对这一挑战，本研究基于WLAN 的实测数据，重点分析网络拓扑、节点间RSSI、
信道接入机制和干扰等因素对系统吞吐量的影响，力求构建一个更为精确的吞吐量预测模
型。通过该模型，未来能够对WLAN 系统进行优化，从而在多个场景中为用户提供便利。


1.2 问题重述


   WLAN 网络的系统吞吐量是衡量网络性能的关键指标，影响其性能的主要因素包括节
点间的RSSI、信道竞争接入机制、CCA 门限、NAV 机制等。在WLAN 网络中，AP 和STA
的发送机会、数据传输速率（PHY Rate）、干扰情况等都会影响整体的吞吐量表现。本研
究将针对三个关键问题，对WLAN 网络的相关参数进行分析建模，探索不同情况下对系统
吞吐量的预测方法。
  问题一：AP 发送机会的影响分析
  在WLAN 网络中，AP 的发送机会受网络拓扑、业务流量、节点间RSSI 和CCA 门限
等因素影响。AP 与STA 的相对位置决定了RSSI，业务流量大小影响信道竞争，CCA 门限
则判断信道是否空闲。根据这些信息可建立模型，分析各因素对AP 发送机会的影响，预
测AP 发送数据帧的总时长，并通过分类或统一建模提高预测精度。
  问题二：AP 发送速率的建模
   AP 发送速率由调制编码方案（MCS, NSS）决定，受节点间RSSI 和信道干扰影响。通
过分析RSSI 和CCA 门限信息，发现AP 在不同传输阶段的选择不同，RSSI 较大时干扰增
加，STA 信噪比下降。基于RSSI 和门限信息可建立模型，预测AP 最常用的（MCS, NSS），
进而估算AP 发送速率。
  问题三：系统吞吐量的预测模型
   WLAN 系统吞吐量受AP 发送机会、PHY 速率、信道干扰等因素影响。基于网络拓扑、
RSSI、信道门限信息，可构建综合模型预测吞吐量。因RSSI 信息难完全反映信道变化，
使用实测数据中的真实数据帧（MCS, NSS）作为输入变量，通过分类或统一建模方法，提
高预测精度，为WLAN 网络优化提供参考。

              二、模型假设



2.1 基本假设


  根据提供的实测数据集，模型假设应基于实际观测数据的特征与条件进行设定。结合
训练集的网络拓扑、RSSI、业务流量等关键要素，以下是针对模型假设的分析和总结：

2.1.1 信道条件假设

    (1) 短时间内信道条件相对稳定
  基于实测的RSSI 数据，我们可以假设在短时间内信道的波动幅度较小，尤其是RSSI
能够反映大尺度的信道变化。因此，数据建模时可以认为RSSI 在短时间内不会出现剧烈波
动，适合进行吞吐量的预测。
    (2) 环境噪声和干扰相对可控
  通过实测数据中的信号强度与干扰评估，假设环境噪声及干扰在短期内影响有限，信
道模型中可忽略小规模的噪声变化。

2.1.2 节点行为假设

    (1) 节点按照标准协议通信
    AP 和STA 之间遵循IEEE 802.11 协议的标准通信机制，包括使用CCA 机制检查信道是
否空闲、采用NAV 机制协调信道访问，确保模型能够基于这些行为预测各节点的吞吐量。
    (2) 基于实测RSSI 的干扰处理
  节点间的RSSI 数据将作为评估干扰程度的基础，假设节点能够根据实际信号强度调
整通信速率（MCS）与空间流数（NSS）。

2.1.3 干扰假设

    (1) 干扰源以邻近AP 为主
  从训练数据中的AP 间RSSI 值来看，邻近AP 是主要的干扰源。我们假设干扰主要来
自信道复用的AP，且干扰强度与RSSI 直接相关。
    (2) 多路径传播影响可忽略
  由于多根天线的RSSI 值已经在数据中汇总处理，多路径传播效应在模型中不再作为
主要考虑因素。

           三、问题一的建模与求解



3.1 问题分析


  问题一的核心是通过分析WLAN 网络的实际训练数据集，确定各个因素对AP 发送机
会的影响程度，并基于这些影响因素构建一个定量模型。这个模型的输出是AP 在特定网
络拓扑和干扰环境下的发送机会，而发送机会与AP 在网络中的位置、流量类型、干扰强
度等密切相关[1]。
     (1) 网络拓扑
   AP 与STA 之间的物理位置关系决定了节点之间的信号强度（RSSI），该强度直接影
响AP 与STA 之间的通信质量。拓扑中的AP 之间的相对位置决定了干扰的严重程度，特
别是在同频AP 较为密集的场景中，信道竞争更为激烈，从而减少AP 的发送机会。因此，
网络拓扑中的节点分布对AP 发送机会的影响十分显著。
     (2) RSSI（接收信号强度指示）
   较高的RSSI 通常表示更好的通信质量，AP 的发送机会也随之增加。然而，在高密度
部署场景中，较低的RSSI 可能导致更多的信号干扰，从而降低AP 的发送成功率。RSSI
的波动对干扰强度以及发送成功率有直接影响，因此在建模过程中，RSSI 是不可忽视的因
素。
     (3) 业务流量的类型和规模
   WLAN 中的业务流量通常分为UDP 和TCP 两种。UDP 协议是无连接的，数据包无需
确认便可发送，因此AP 的发送机会较大；而TCP 协议则需要数据包发送后进行确认，这
增加了发送过程中的等待时间，特别是在高负载情况下，AP 的发送机会会由于频繁的ACK
等待而减少。此外，业务流量的大小也直接影响信道的占用时间，较大的数据包会延长AP
的发送时间，从而减少其他节点获取信道的机会。
     (4) 门限参数（包括PD、ED、NAV 等）
   PD 和ED 门限通过判断信道是否空闲来决定AP 是否能够发送数据，较低的门限值意
味着AP 更容易感知到其他设备的信号干扰，进而减少发送数据的机会。此外，NAV 门限
通过设置静默期来限制其他节点使用信道，NAV 静默期越长，AP 的发送机会越少。
  问题一的目标是分析各参数对AP 发送机会的影响程度，并预测每个AP 的发送机会，
即发送数据帧序列的总时长。通过观察训练集，可以发现其中包含大量实验测量数据，因
此首先需要对训练集进行数据清洗，排除异常值，填补缺失值，并删除明显无关的特征；
接着对数据进行处理，提取与发送数据帧序列总时长存在显著关联的特征；然后将发送数
据帧序列的总时长设定为预测目标，建立随机森林模型进行求解；最后，利用该模型确定
各参数的影响强弱顺序，并对测试集中的样本进行发送数据帧序列总时长的预测。

3.2.2 分析参数

  基于上述分析，问题一中的模型将会构建一个框架，用数学公式描述AP 发送机会与
网络拓扑、业务流量、门限参数及RSSI 等多个影响因子之间的关系。通过这些公式，能够
有效预测AP 的发送机会，并为后续的系统吞吐量预测提供基础。
     1)  RSSI (Received Signal Strength Indication)
       RSSI 是衡量信号强度的指标。信号强度越高，成功发送的机会越大，较高的RSSI
    与较低的干扰相关，增加了AP 发送的机会。此外，BSS_ID 列的数据表明信号的
    源AP 信息。
     2) 业务流量类型 (Protocol type)
     数据传输使用的协议类型protocol 会影响数据包的发送方式和频率，从而影响AP
    的发送机会。
     3) AP 的发送功率
      AP 的发送功率高低会影响信号的传输质量，同时也会改变对其他AP 发送信号的
    干扰，因此总体来说会影响AP 的发送机会。
     4) CCA 门限 (Clear Channel Assessment Thresholds)
     CCA 分为包检测门限（PD）和能量检测门限（ED），对应列分别为pd 和ed。当
       RSSI 高于PD 时，AP 能够侦听到信号并作出响应。若低于ED，信道被判定为繁
     忙，AP 则不能发送数据。因此，PD 和ED 门限的关系直接影响AP 的发送机会。
     5) NAV 门限 (Network Allocation Vector)
      NAV 通过nav 列表示，指示在特定时间段内其他节点不应发送数据。如果AP 正
    在使用信道，周围的节点必须静默，这将影响AP 的发送机会。
     6) 网络拓扑
     WLAN 网络的拓扑结构会对节点之间信号的干扰造成影响，从而影响AP 的发送
    机会。在本题中，网络拓扑的差异体现在loc_id 的不同。

4.1 问题分析


  除了发送机会外，WLAN 网络的吞吐量还受到PHY 速率和数据帧大小的影响。AP 在
向不同STA 发送数据时选择的（MCS, NSS）组合与信道状况紧密相关。因此，我们需要
基于实测数据，构建模型来预测AP 发送数据时最常使用的（MCS, NSS）组合。
  问题二的核心是通过分析SINR（信噪干扰比）与传输方式之间的关系，预测AP 在不
同情况下使用的PHY Rate，并根据PHY Rate 推断出（MCS, NSS）的组合类型。我们将根
据节点间的RSSI 信息、PHY Rate、AP 的传输方式和干扰情况进行分析。
     (1) 数据分析与处理
  通过观察2AP 数据，可以发现同一实验组中，AP 使用的（MCS, NSS）组合会有所不
同。因此，我们需要对每条数据进行独立分析。尽管实验中的组合差异不大，但我们可以
认为（MCS, NSS）组合与实验中多个数据项（如RSSI、PHY Rate 等）相关。我们从多个
实验数据中提取dss（数据流类型）的信息，结合RSSI 和PHY Rate 进行分析。
     (2) PHY Rate 与（MCS, NSS）组合的映射关系
  根据数据分析，可以推断（MCS, NSS）组合与PHY Rate 存在映射关系。我们通过观
测和实验数据，构建一个（MCS, NSS）组合与PHY Rate 的映射表格，预测PHY Rate 的范
围，并进一步推断其对应的（MCS, NSS）组合。
     (3) 计算𝑺𝑰𝑵𝑹
   PHY Rate 与AP 的传输方式密切相关，信号强度（𝑅𝑆𝑆𝐼）和信干燥比（𝑆𝐼𝑁𝑅）是关键
因素。通过计算STA 与不同AP 之间的RSSI 差异，我们可以得出STA 接收数据时的𝑆𝐼𝑁𝑅。
𝑆𝐼𝑁𝑅（单位为dB）的计算方式如下：

                𝑆𝐼𝑁𝑅= 𝑅𝑆𝑆𝐼𝐴𝑃−𝑆𝑇𝐴−𝑁𝑜𝑖𝑠𝑒，同步传输
                 {                                                        (4 −1)
             𝑆𝐼𝑁𝑅= 𝑅𝑆𝑆𝐼𝐴𝑃−𝑆𝑇𝐴−(𝑅𝑆𝑆𝐼0 + 𝑁𝑜𝑖𝑠𝑒)，异步传输
   其中，𝑅𝑆𝑆𝐼𝐴𝑃−𝑆𝑇𝐴是关联AP 到STA 的信号强度，𝑅𝑆𝑆𝐼0是邻近AP 对STA 的干扰强
度，𝑁𝑜𝑖𝑠𝑒是环境噪声基准值。𝑆𝐼𝑁𝑅的高低将直接影响PHY Rate 的选择，并通过此信息
预测（MCS, NSS）组合。
     (4) 数据清理与处理
  由于实验中存在一些异常数据点，我们将使用去除最大10%和最小10%SINR 值的策
略，来确保分析过程的稳健性。这些极端数据可能由于环境噪声或其他外部干扰因素导致，
去除后能够更加准确地反映真实的信道状况。
  在解决问题二时，我们根据𝑅𝑆𝑆𝐼数据计算𝑆𝐼𝑁𝑅，然后通过PHY Rate 的预测范围，推
测最有可能的（MCS, NSS）组合。模型的输入包括AP 与STA 之间的信号强度，模型输出
的PHY Rate 与（MCS, NSS）组合之间的关系则通过预先构建的映射表得到。
  然后，采用去除异常值（最大10%和最小10%）的方法进行数据清理，进一步优化模
型的预测精度。接着，使用问题一中的预测结果来估算同步与异步传输的比例，从而更准
确地预测PHY Rate。
  通过这种方式，我们可以确定网络中的主要传输方式，并最终预测AP 最常用的（MCS,
NSS）组合，反映了网络的𝑆𝐼𝑁𝑅水平和PHY Rate。

4.2 模型构建与求解


  我们选择使用卷积神经网络（CNN）作为核心模型进行分析和预测。CNN 擅长处理具
有空间依赖性的数据，能够通过卷积操作有效提取输入矩阵中的局部和全局特征。在无线
通信网络中，不同AP 与STA 之间的信号传输及干扰情况可以通过RSSI 和SINR 值表示，
这些值构成的矩阵具有空间结构，适合通过CNN 进行处理和特征提取。为了确保模型能
够准确、高效地学习，这之前，我们需要对原始数据进行预处理，以提高模型的收敛速度
和预测精度。

4.2.1 数据预处理

  对于无线通信系统中的信号传输建模，预处理的主要任务是处理RSSI 和SINR 等关键
特征数据。
     (1) 数据清洗
     a) 缺失值处理
  在实际数据集中，某些AP 或STA 由于物理环境的干扰或设备问题，导致部分RSSI
或SINR 数据缺失。我们通过对缺失数据进行分析，对缺失数据进行了填补，使得后续训
练过程可以正常进行。
     b) 异常值检测
   我们使用Z-score 方法检测了RSSI 和SINR 中的异常值，定义z 分数超过3 倍标准差
的点为异常。检测到的异常值已通过剔除极端值（即去除最大10%和最小10%）的策略进
行了清理，从而提高数据的稳健性和模型训练的准确性。Z-score 的计算公式如下：
                        𝑋−𝜇
                     𝑍=                                   (4 −2)
                                     𝛿
  其中，是𝑍值表示当前数据点距离数据集平均值的标准差个数，𝑋是数据集中某一列的
具体数值，𝜇表示数据集中某一列的平均值，𝛿是数据集的标准差。
     (2) Akima 插值拟合算法
  在数据处理与分析中，我们发现，不同实验中样本的测量间隔不同，这导致了RSSI 的
测量值数目不同，在特征处理时无法统一计算，因此需要对测量数据的数目进行统一。
  经过对数据集的RSSI 测量值长度进行分析，我们发现：虽然多数测量数据的数量不

不丢失RSSI 的数据特征，我们选择将所有RSSI 测量数据统一扩充到较大的数值。
  经过分析，最长的RSSI 测量值队列长度为521，因此我们选择将数据量统一为540 个。

补充。

4.2.2 模型选择和优化

  我们分析多个AP 与STA 之间的网络拓扑，即每个终端设备从多个AP 接收信号，这
些信号由有用的传输信号和噪声信号组成。通过分析这些信号的干扰情况，我们可以计算
每个设备的SINR（信号干扰噪声比）。随后，我们将这些SINR 值拼接成矩阵，并输入到
卷积神经网络（CNN）中进行进一步的分析和预测。接下来，我们将详细分析该模型的构
建过程、公式以及相关的参数。
(1) 计算每个设备的SINR
  对于每个设备𝑆𝑇𝐴 𝑖，接收的信号可以分为来自目标𝐴𝑃𝑚的有效信号，以及来自邻区𝐴𝑃𝑛
的干扰信号和环境噪声。例如，对2AP 的网络拓扑，设定𝑆𝑇𝐴 1和𝑆𝑇𝐴 2分别从𝐴𝑃1和𝐴𝑃2接
收信号。对于每个𝑆𝑇𝐴，接收的信号分为目标AP 的有效信号和邻区AP 的干扰信号，我们
计算每个设备的𝑆𝐼𝑁𝑅值。
   𝑆𝑇𝐴 1从𝐴𝑃1接收有效信号，从𝐴𝑃2接收干扰信号。因此，𝑆𝑇𝐴 1的𝑆𝐼𝑁𝑅公式为：

                    𝑆𝐼𝑁𝑅𝑆𝑇𝐴1−𝐴𝑃1 = 𝑅𝑆𝑆𝐼𝐴𝑃1−𝑆𝑇𝐴1 −(𝑅𝑆𝑆𝐼𝐴𝑃2−𝑆𝑇𝐴1 + 𝑁𝑜𝑖𝑠𝑒)          (4 −6)

   𝑆𝑇𝐴 2从𝐴𝑃2接收有效信号，从𝐴𝑃1接收干扰信号。因此，𝑆𝑇𝐴 2的𝑆𝐼𝑁𝑅公式为：

                    𝑆𝐼𝑁𝑅𝑆𝑇𝐴2−𝐴𝑃2 = 𝑅𝑆𝑆𝐼𝐴𝑃2−𝑆𝑇𝐴2 −(𝑅𝑆𝑆𝐼𝐴𝑃1−𝑆𝑇𝐴2 + 𝑁𝑜𝑖𝑠𝑒)          (4 −7)
  推广到3AP 的网络拓扑中也是类似的计算方式，因此我们设定了统一的𝑆𝐼𝑁𝑅计算公
式：

                 𝑆𝐼𝑁𝑅𝑆𝑇𝐴𝑖−𝐴𝑃𝑚= 𝑅𝑆𝑆𝐼𝐴𝑃𝑚−𝑆𝑇𝐴𝑖−(𝑅𝑆𝑆𝐼𝐴𝑃𝑛−𝑆𝑇𝐴𝑖+ 𝑁𝑜𝑖𝑠𝑒)          (4 −8)

   其中，𝑅𝑆𝑆𝐼𝐴𝑃𝑚−𝑆𝑇𝐴𝑖表示𝑆𝑇𝐴 𝑖从𝐴𝑃𝑚接收有效信号，从𝐴𝑃𝑛接收干扰信号，𝑁𝑜𝑖𝑠𝑒表示环

境噪声基准值。

(3) CNN 模型的输入与卷积层分析
  在构建的模型中，SINR 矩阵作为输入传入到卷积神经网络（CNN）。卷积神经网络擅
长从矩阵形式的数据中提取局部和全局特征，尤其适用于分析空间依赖性强的数据。
   CNN 的卷积层可以使用不同的卷积核尺寸来提取信号传输的局部特征。对于不同大小
的矩阵，我们可以使用自适应池化层（Adaptive Pooling Layer）来调整矩阵的尺寸，使其达
到固定大小。这样可以保证网络在处理不同大小的输入时具有灵活性。具体操作上，采用
2D 卷积操作，通过多个卷积核（filters）来提取不同的信号特征。模型设有输入矩阵𝑋（表
示不同设备和AP 之间的SINR 值），卷积操作可以表示为：
                   𝑍= 𝑓(𝑊∗𝑋+ 𝑏)                         (4 −10)
  其中，𝑊表示卷积核的权重矩阵，𝑏表示偏置向量，𝑓表示激活函数—𝑅𝑒𝐿𝑈函数。经过
卷积层处理后，得到的输出特征图可以用于分析无线信号传输中的干扰和信道质量。
(4) 自适应池化与特征提取
  为了保证CNN 的输入尺寸一致，我们使用了自适应池化层。自适应池化层可以根据
输入矩阵的大小，动态调整池化区域的尺寸，将矩阵缩放到固定的大小。自适应池化的公
式为：
                                           ℎ′ = ⌊ℎ                              (4 −11)                                          𝑘⌋
                                   𝜔′ = ⌊𝜔                              (4 −12)                                       𝑘⌋
  其中，ℎ和𝜔分别表示为输入矩阵的高度和宽度，𝑘是池化因子，ℎ′和𝜔′是池化后的矩
阵高度和宽度。池化操作确保可以处理不同大小的𝑆𝐼𝑁𝑅矩阵输入，同时保留了重要的空间
特征。
(5) 参数分析
  在问题二的模型中，关键的参数包括：
    a) 𝑺𝑰𝑵𝑹计算中的信号强度和干扰强度
  这些数据可以通过实际测量的𝑅𝑆𝑆𝐼值来确定。模型中的参数调整主要集中于如何精确
地建模信号强度和干扰强度的影响。
    b) 卷积核大小
  卷积核的大小决定了CNN 捕捉局部特征的能力。较大的卷积核可以捕捉全局特征，
而较小的卷积核则适合捕捉局部变化。
    c) 池化层设置
  池化层的设置可以影响模型处理不同尺寸输入的能力。自适应池化使得我们可以处理
不同维度的输入，同时保持输出尺寸一致性。

           五、问题三的建模与求解



5.1 问题分析


  在WLAN 网络中，系统吞吐量不仅依赖于发送机会，还受到物理层速率（PHY Rate）
和数据帧大小的影响。AP 通过自适应调制编码（AMC）算法选择调制编码方案（MCS, NSS），
其选择受传输方式、干扰情况、信道条件以及RSSI 的影响。我们需要根据问题一和问题二
中的分析，构建预测模型，利用实测数据中的真实（MCS, NSS）组合来预测网络吞吐量。
  问题三的核心在于系统吞吐量的建模不仅要考虑多个AP 之间的竞争情况、业务流量
的类型（如TCP 和UDP），还要将二进制指数退避算法、竞争窗口（CW）、网络分配矢
量（NAV）等因素纳入模型。吞吐量的变化与信道状况密切相关，因此我们需要根据不同
同频AP 的数量分类建模，或者统一建模。
     (1) 自适应调制编码（AMC）
    MCS（Modulation and Coding Scheme）和NSS（Number of Spatial Streams）:这两个参
数决定了PHY 速率。高MCS 和NSS 能够支持更高的吞吐量，但对信道质量要求更高
     (2) 二进制指数退避与竞争窗口的影响
  无线网络中的每个AP 通过二进制指数退避算法竞争信道，每次冲突后竞争窗口（CW）

                                                   24

===== PDF PAGE 26 =====
增大，增加了传输的延迟。因此，吞吐量不仅取决于PHY Rate，还与AP 在竞争过程中等
待信道空闲的时间有关。在传输失败后，AP 会在ACKTimeout 后重传，竞争窗口翻倍，
CW 的大小直接影响数据包传输的频率。需要在模型中考虑CW、DIFS（DCF 帧间距）以
及退避计数器的变化对吞吐量的影响。
     (3) 业务流量类型的影响
  业务流量的类型也是影响吞吐量的重要因素。对于UDP 流量，报文的大小和发送时间
间隔影响吞吐量；对于TCP 流量，发送方需要根据网络拥塞情况调整发送速率。当丢包率
高时，TCP 流量的速率下降，反之，当网络状况良好时，TCP 流量速率提升。此外，TCP
ACK 也是一种数据流，上行与下行流量的不对称性会影响吞吐量的预测。因此，模型中需
要分别考虑TCP 和UDP 流量的特性，尤其是TCP 流量中丢包率对吞吐量的动态调节作
用。
     (4) 聚合机制与吞吐量
  在WLAN 网络中，AMSDU 和AMPDU 聚合机制允许AP 将多个数据包聚合成一个帧
进行传输，从而提高吞吐量。当小包的数量增加时，聚合机制有效减少了帧头的开销，提
高了传输效率。因此，吞吐量的预测不仅依赖于单个数据包的传输速率，还与聚合的MPDU
和MSDU 数量有关。我们需要在模型中考虑聚合后的帧长度及其对系统吞吐量的贡献。
  对于问题三的求解，我们基于实测数据中的（MCS, NSS）组合，预测每个AP 的PHY
Rate。然后，通过二进制指数退避算法，结合竞争窗口和信道空闲时间，估算AP 的传输延
迟。我们还根据业务流量类型，考虑TCP 丢包率对传输速率的调节作用。最后，通过
RTS/CTS 机制与聚合机制，进一步调整模型输出的吞吐量。


5.2 模型构建与求解


  为了准确预测系统的吞吐量，我们选择使用卷积神经网络（CNN）作为核心预测模型。
CNN 在处理空间依赖性较强的数据时表现出色，尤其适用于提取无线信道中的局部和全局
特征。通过将RSSI、SINR、竞争窗口（CW）、业务流量类型、MCS、NSS 等特征因素作
为输入数据，结合问题一的𝑠𝑒𝑞_𝑡𝑖𝑚𝑒和问题二实际测量的（MCS, NSS）组合，我们构建了
基于CNN 的模型求解问题三。

5.2.1 数据预处理

  我们首先对实测数据进行了全面的数据预处理，确保输入数据质量和一致性。数据预
处理的主要步骤包括：
     (1) 缺失值处理
  对于部分缺失的RSSI 和SINR 数据，我们使用平均值进行填充。
     (2) 归一化处理
  为了防止不同数据量级影响模型训练效果，我们对所有特征进行了归一化处理，将数
据缩放至[0,1]范围。
     (3) 随机回退处理
  二进制指数退避算法是无线网络中常用的机制，控制数据帧发送时的竞争窗口。该算
法会直接影响吞吐量的变化，因此在模型中需要考虑每次数据传输时的回退机制。
  𝐶𝑊𝑚𝑖𝑛和𝐶𝑊𝑚𝑎𝑥在不同节点的竞争窗口初始值可能不同，模型应结合𝐶𝑊𝑚𝑖𝑛和𝐶𝑊𝑚𝑎𝑥
来建模数据传输的成功率。
  重传𝑟次失败后，数据帧会被丢弃，这将直接影响系统的吞吐量。因此，应将重传次数

===== PDF PAGE 27 =====
作为一个关键特征，并且要结合CW 值对其进行处理。
  在数据预处理时，需提取出各节点的𝐶𝑊𝑚𝑖𝑛、𝐶𝑊𝑚𝑎𝑥，重传次数𝑟，并根据传输失败次数
的累积，来调整发送成功的概率。
     (4) 聚合与分包机制
   MSDU 和MPDU 的聚合机制会直接影响吞吐量的计算，特别是对于小包传输来说，
聚合可以显著减少信道占用时间，提高有效数据的传输效率。
  在数据预处理时，应处理以下关键信息：
   AMSDU 和AMPDU 聚合个数——通过分析每个数据包的聚合情况（MSDU 和
MPDU），可以计算出其对吞吐量的影响。实际数据中的𝑛𝑢𝑚_𝑎𝑚𝑝𝑑𝑢和𝑛𝑢𝑚_𝑎𝑚𝑠𝑑𝑢这两
个特征可以用于表示数据帧的聚合情况。
  数据包大小——通过统计不同流量类型下的数据包大小，结合其聚合效率，预测总的
吞吐量。
     (5) 数据传输类型及丢包处理
  数据传输类型（如TCP 和UDP）对吞吐量有显著影响。UDP 是单向流，通常用于不
要求确认的快速数据传输，而TCP 是双向流，具有丢包重传机制。丢包率𝑝𝑒𝑟是影响TCP
吞吐量的关键指标。在预处理阶段：
  确认𝑝𝑒𝑟，因为在模型中丢包率的高低对吞吐量影响较大，特别是对TCP 流量，丢包
率较高时，数据重传会降低总体吞吐量。
  模型应区分TCP 和UDP 流量，且需要计算TCP 的ACK 数量与实际数据量的比例，
这有助于更准确地预测下行和上行之间的带宽占用情况。针对不同类型的流量制定不同的
特征处理方案。TCP 包含重传机制，因此需结合丢包率𝑝𝑒𝑟对其进行处理。
     (6) RTS-CTS 机制
  通过RTS 和CTS 的握手机制，可以有效减少无线网络中数据包的碰撞。但这种机制
会额外消耗信道资源，因此，在吞吐量预测模型中，RTS-CT 的开销也是一个重要因素。
  数据帧在RTS 和CTS 的握手过程中会占用部分信道资源，影响总的吞吐量。因此，
在预处理时应提取这些控制帧的开销数据，并将其作为特征之一。如果某个AP 的碰撞次
数较多，则表明其信道竞争激烈，这时RTS-CTS 机制的开销将会增大，影响吞吐量。

            六、模型的改进与结论



6.1 模型改进建议


  在问题三的无线网络吞吐量预测中，卷积神经网络（CNN）虽然擅长处理局部特征和
时间序列中的短期模式，但它也有一些不足，尤其是在处理无线网络中的长时间依赖性、
非线性复杂性等方面。
  处理长时间依赖的能力有限：CNN 擅长捕捉局部的时间序列模式，但对于长期依赖特
征的捕捉能力较弱。无线网络吞吐量通常不仅受当前时刻的信号强度和丢包率影响，还与
长时间范围内的网络状态有关，而CNN 可能无法很好地处理这种时间序列的长程依赖性。
  缺少对序列特征的捕捉能力：CNN 更多地关注局部信息的卷积提取，但吞吐量预测中
涉及的许多特征，比如信道竞争和干扰等，具有长期时间序列依赖。仅使用CNN 可能会忽
略这些时序相关性，无法捕捉较复杂的模式。
  为了提高CNN 模型的性能，针对上述不足，可以进行以下几方面的改进：
     (1) 添加Dropout 层
    Dropout 是一种防止过拟合的技术，尤其在面对小规模数据集或复杂的无线网络环境
时，Dropout 可以通过随机屏蔽一部分神经元来减少模型对某些特征的过度依赖。其核心
思想是每一轮训练中随机忽略部分神经元，使得模型不会过度依赖某些局部特征。这样可
以使模型更具泛化能力，从而在测试集上的表现更加稳定。
    Dropout 的正则化效果体现在训练过程中，某些神经元被随机忽略（即它们的激活值被
设置为零），从而迫使网络学会更加鲁棒的特征表示，减少对训练集的过拟合。可以在CNN
的卷积层或全连接层后加入Dropout 层，典型的Dropout 比率通常在0.2 到0.5 之间。
     (2) 结合RNN
   CNN 擅长处理局部的时间序列特征，但对于长时间的依赖特征处理能力较弱。在问题
三中，吞吐量预测可能涉及到多个时间步的数据，比如信道状态、历史吞吐量、网络负载
等。这时，结合RNN（如LSTM 或GRU）可以更好地捕捉这些长时依赖的特征。
   RNN 尤其是LSTM（长短期记忆网络）和GRU（门控循环单元）是处理时间序列数据
的经典模型，它们可以通过记忆单元来捕捉长时依赖特征。LSTM 可以记住长时间范围内
的相关信息，特别适合处理有时间延迟的网络变化对吞吐量的影响。
     (3) 加入注意力机制
  在很多深度学习任务中，注意力机制已经证明能够有效提升模型的性能。注意力机制
通过让模型学会关注输入数据中最重要的部分，帮助模型选择对吞吐量预测最相关的特征。
通过引入注意力机制，模型可以更加灵活地聚焦于影响网络性能的关键特征，如某些时间
段的网络拥塞或信号强度的变化。


6.2 主要结论


  本研究通过构建基于卷积神经网络（CNN）的模型，对无线局域网（WLAN）中的吞
吐量进行了深入的预测和分析，得出以下主要结论：
     (1) 吞吐量与信道条件、流量类型及丢包率等密切相关
  吞吐量受到多个因素的综合影响，主要包括：
     a) 信号强度越高，数据传输的可靠性越好，吞吐量越高。RSSI 是衡量信道质量的关

                                                   30

===== PDF PAGE 32 =====
    键因素，强信号能够减少数据传输中的丢包率，进而提高吞吐量。
     b) 丢包率越高，意味着网络中传输数据包的错误率增加，导致重传次数增多，从而
    降低有效吞吐量。减少丢包率是提高吞吐量的关键。
     c)  TCP 流量由于重传和确认机制，其吞吐量容易受到丢包率的影响。而UDP 流量没
    有重传机制，传输速率较快，但对信道质量要求较高。
     d) 数据包的聚合机制在高负载环境下显著提高了吞吐量。通过将多个数据包聚合成
    一个更大的数据包传输，可以减少每次传输的信道竞争和控制开销，进而提升整
    体吞吐量。
     e) MCS 和NSS 的组合共同决定了无线传输速率，进而影响了吞吐量。在实际应用
    中，不同的MCS 和NSS 组合会产生不同的物理层数据速率（PHY Rate）。
     (2) 提高信道中的吞吐量的有效策略
  在复杂的无线网络环境中，提升吞吐量可以通过以下策略：
  通过减少冲突、提高信道利用率，可以显著提升吞吐量。引入RTS-CTS 机制可以有效
减少信道争用时的数据包碰撞，特别是在高密度网络中。
  适当调整清除信道评估（CCA）和网络分配向量（NAV）门限，使AP 能够在干扰较
少的情况下更灵活地占用信道，增加信道的利用效率。
  通过提升网络中信号接收的稳定性、增强抗干扰能力，可以减少数据包的丢失和重传，
从而提升吞吐量。
  使用更有效的AMSDU 和AMPDU 数据包聚合机制可以提高信道利用效率，减少信道
空闲时间，提高数据的传输速率，最终提升整体吞吐量。
     (3) 使用模型预测吞吐量的有效性
  本研究中提出的基于CNN 的模型能够准确预测无线网络中的吞吐量，并为网络管理
者提供有价值的参考：
  局部特征提取：通过卷积层，模型能够提取影响吞吐量的局部模式和特征，尤其是信
号强度、丢包率等局部变化信息，有效预测不同网络条件下的吞吐量变化。
  时间序列特性分析：通过对多时间步的信道状态数据进行处理，模型能够预测未来时
间段内的吞吐量，从而为网络运营者提供动态优化的依据。


6.3 研究贡献


  本研究为无线网络中的吞吐量预测提供了一种新的解决方案，并在深度学习应用于无
线网络性能预测方面做出了有益探索。通过综合应用多种模型改进技术，研究有效提升了
模型的预测精度和适应能力，为无线网络性能优化提供了新的工具和参考。
     (1) 构建基于CNN 的无线网络吞吐量预测模型
  本研究首次将卷积神经网络（CNN）应用于无线局域网（WLAN）的吞吐量预测问题
中。通过对无线信号强度（RSSI）、丢包率（PER）、流量类型、聚合机制等多个网络特
征的综合分析，建立了一个高效的深度学习模型。该模型利用CNN 擅长的局部特征提取
能力，能够在复杂的无线网络环境下有效预测AP 的吞吐量。这种方法为传统的吞吐量预
测模型提供了新的视角，极大地提高了预测精度。
     (2) 拓展无线网络数据处理框架
  研究中不仅提出了一种新的基于深度学习的吞吐量预测模型，还对无线网络数据的处
理流程进行了系统化设计。包括数据清洗、特征提取与工程、时间序列化等预处理步骤，
为后续的网络性能优化研究提供了一个完整的框架。这一框架不仅适用于本研究的问题，
还可为未来无线通信中其他预测任务（如信道状态预测、网络延迟预测等）提供参考。

     (3) 对无线网络优化的实际应用
  本研究提出的吞吐量预测模型具有实际应用价值，特别是在高密度无线网络的部署和
优化中。通过准确预测不同接入点（AP）的吞吐量，网络运营商可以更好地管理网络资源，
减少信道拥塞，提高网络整体性能。本模型可用于智能网络管理平台，支持动态网络资源
调度、负载均衡等优化措施。
     (4) 为后续研究提供基线
  本研究提出的基于CNN 和RNN 的吞吐量预测模型为未来的研究奠定了基线，后续研
究可以在此基础上进一步优化网络架构、改进训练算法或引入新的正则化技术，提升模型
性能。同时，研究中探索的多特征融合方法和模型架构可以被广泛应用于其他无线网络性
能预测任务中，推动该领域的进一步发展。

def pad_lists_and_min(series1, series2, pad_value=-100):
   # 定义目标长度
     target_length = 540


    def pad_and_interpolate(series):
      # 对每个列表进行插值
         interpolated_series = []
          for lst in series:
                     if len(lst) == 1:
             # 如果列表只有一个元素，直接复制
                   interpolated_lst = np.array([lst[0]] * target_length)
                  elif len(lst) < target_length:
                x = np.arange(len(lst))
                  interpolator = Akima1DInterpolator(x, lst)
               x_new = np.linspace(0, len(lst) - 1, target_length)
                   interpolated_lst = interpolator(x_new)
               else:
                   interpolated_lst = np.array(lst[:target_length])
              interpolated_series.append(interpolated_lst)


         return interpolated_series


   # 对两个系列进行插值
     interpolated_series1 = pad_and_interpolate(series1)
     interpolated_series2 = pad_and_interpolate(series2)



   # 计算两个列表中每个元素的差值
     result_series =  [list(np.array(lst1)  -  np.array(lst2))  for  lst1,  lst2  in  zip(interpolated_series1,
interpolated_series2)]


   # 将每一行复制并新增为下一行
     doubled_result_series = []
     for row in result_series:
         doubled_result_series.append(row)
         doubled_result_series.append(row.copy())
   # 将列表输出为csv 文件
     #pd.DataFrame(result_series).to_csv('result_series.csv',index=False)
    return pd.Series(doubled_result_series)

class CNNRegression(nn.Module):
    def __init__(self):

         self.conv1 = nn.Conv1d(in_channels=1, out_channels=64, kernel_size=2)
         self.conv2 = nn.Conv1d(in_channels=64, out_channels=128, kernel_size=2)
          self.pool = nn.MaxPool1d(kernel_size=2, stride=2)
           self.fc1 = nn.Linear(128 * pool2_output_size, 100)
           self.fc2 = nn.Linear(100, 50)
           self.fc3 = nn.Linear(50, 1)


    def forward(self, x):
        x = torch.relu(self.conv1(x))
        x = self.pool(x)
        x = torch.relu(self.conv2(x))
        x = self.pool(x)
        x = x.reshape(x.size(0), -1)
        x = torch.relu(self.fc1(x))
        x = torch.relu(self.fc2(x))
        x = self.fc3(x)
