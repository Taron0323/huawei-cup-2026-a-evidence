# 从赛题到可检验答案

以下是基于2024年获奖论文比较后提出的实践方法，不是官方流程或分值表。采用其中能解决当前问题的部分。

## 1. 用输出组织工作

先用一张简表连接各问：题目动作词、必须交付的对象、输入及来源、方法、结果文件、检验方式、当前缺口。若前一问提供后一问输入，记录接口中的单位、对象顺序、预测误差与训练/推理差异。

例如，发送机会预测进入吞吐量预测时，训练时输入真实发送时长而应用时输入估计时长，会改变输入分布。应评估这项误差传播，而不是仅把两问的公式放在相邻章节。

不要为了视觉上完整，把本来独立的问题强行串联。题面明确提供的真实中间变量可以使用；必须根据实际授权输入判断，不能一概把真实中间量称为泄漏。

## 2. 先确定比较协议

一个结果记录至少能回答以下问题，可放在已有日志中，无需另造数据库：

| 字段 | 应能回答的问题 |
| --- | --- |
| 数据与对象 | 哪个版本，哪些样本，是否同次实验/同设备/邻近时空？ |
| 划分 | 谁进入训练、调参、最终评估，为什么贴合实际用途？ |
| 输入 | 预测时可否获得，预处理在哪部分数据上拟合？ |
| 目标与单位 | 原始量、归一化量还是对数量，如何恢复原尺度？ |
| 模型与参数 | 代码版本、参数、随机种子、训练或求解预算？ |
| 指标 | 数学定义、方向、聚合方法、样本量？ |
| 产物 | 配置、日志、预测/方案、指标、图表如何对应？ |

拟合预处理、特征选择和调参应在训练侧完成；分类按合适的分层保持类别覆盖，时间预测按时间，跨对象任务按对象。留出方式由问题决定。记录不能把原始变量全部可用、IID或数据清洁当作默认事实。

## 3. 不同问题的关键验证

| 类型 | 基线和主要检验 | 最容易误读之处 |
| --- | --- | --- |
| 预测/分类 | 常规模型；独立留出；按材料/设备/区域/难例切片；必要时置信区间 | 高训练准确率、随机行拆分、类别不平衡、反变换前后指标混用 |
| 机理/参数估计 | 原公式；参数可辨识性与初值；残差；边界量纲 | 拟合好不代表机制成立；相关重要性不等于因果作用 |
| 优化/调度 | 可行规则或小例精确解；逐项约束；重复运行；预算及目标差值 | 收敛曲线不证明全局最优；换单位后权重含义改变 |
| 视频/空间/时间分析 | 提取精度抽检；区域/时间外推；阈值来源；尺度一致性 | 检测准确不等于速度/密度准确；标签定义与输入重合 |
| 仿真/控制 | 解析极限或独立实现；采样/步长收敛；扰动及失败情景 | 自己设定的效益系数不构成真实改善证据 |

验证要对准最可能使核心结论失效的假设。数据少时选择更保守的验证与模型，说明限制，不补造数据。实验无法运行时给出可执行配置和待验证结论，不能生成“模拟的实测值”。

## 4. 一次只回答一个改进问题

推荐顺序：修正输入和单位 → 补全基线 → 定位错误样本/约束 → 提出一个机制 → 做对照 → 决定保留或删除。若差异小于重复运行波动，暂不写“明显提升”。若不改善主要指标但降低计算成本或提高可解释性，按该价值陈述。

在同一实验中同时换数据、特征、结构、损失和调参预算，只能比较两个完整系统，不能将增益归给其中某个模块。

多目标优化先明确方向、物理单位、归一化基准和硬约束。用候选方案展示折中；需要推荐一个方案时根据题面偏好、成本阈值、膝点等明确规则选取。回算原目标值与约束残差；分类变量不能通过随意四舍五入变成合法方案。

## 5. 剩余时间的分配

以下比例只是可调整的工作预算起点，不是赛事规定：约15%用于题面与数据，约25%用于可用基线和逐问答案，约30%用于核心改进和验证，约20%用于写作整合，约10%用于重跑核查与交付。已经处于后期的项目直接按剩余时间排优先级，不重启流程。

优先级依据：影响多少关键结论、失败概率、修复耗时和证据可得性。临近截止先修漏问、不可行方案、量纲和摘要数字，再考虑新算法。

## 6. 可以封版的条件

每问有实际输出；主结果可以从保存的配置和数据追溯；主要增益有可比对照；最危险假设被检查或在结论中收窄；摘要、正文、表格、代码一致；最终文件满足当年格式与AI披露要求。尚未满足的项写明实际状态，不通过添加“优点与不足”段落代替修复。
