# 猫猫范文风格模板 v3：待审核

主要参考：`2024数模国赛C 题-猫猫范文.pdf`。模板已制作成可填写骨架和含算例的演示稿。v3 根据用户最新意见取消二级标题加粗，保留全部公式使用 Latin Modern Math；当前状态为 **PENDING，尚未获得用户批准**。

## 字体对照

| 项目 | 参考 PDF | 当前模板 |
| --- | --- | --- |
| 中文正文 | 宋体，12 pt | SimSun，12 bp |
| 正文行距 | 常规文字行约 15.6 pt | 基本行距 15.6 bp |
| 摘要行距 | 常规文字行约 17.16 pt | 17.15 bp |
| 论文题名 | 宋体加粗，约 15.95 pt | 宋体加粗，16 bp，居中 |
| 一级标题 | 黑体，约 14.05 pt，居中 | 黑体，14 bp，居中 |
| 二级标题 | 楷体，约 14.05 pt | 楷体，14 bp，左对齐 |
| 三级标题 | 宋体加粗，12 pt | 宋体加粗，12 bp，左对齐 |
| 图题、表题 | 楷体，12 pt | 楷体，12 bp；图下表上 |
| 英文和数字 | Times New Roman | Times New Roman |
| 公式 | Cambria Math | Latin Modern Math，标准 LaTeX 数学字体 |
| 段落 | 首行缩进约两字 | 首行缩进两字 |

表中参考值来自 PDF 字体元数据与字符坐标；同字体正常文字行的间距不包含公式或标题留白。TeX 的 `bp` 与这里的 PDF 点等价，均为 1/72 英寸。字号作了小幅取整，标题轻重仍需审核。

## 本版做过的调整

1. 标题编号统一为 `1.`、`1.1.`、`1.1.1.`，一级标题居中，其他标题左对齐；小幅统一各级标题的段前段后距离。
2. A4 四边留 25 mm，保留三线表和页脚中部页码。摘要页从 1 开始，正文接续为 2；这一点按已核对的 2026 全国规范设置，与范文的页码起点不同。
3. 增加可编辑的技术路线图、矢量曲线图、公式交叉引用、代码行号和中文代码标题。图中采用蓝、绿等有限配色，正文保持黑色。
4. 正式骨架使用灰色待填写标记；演示稿用可核对的小型算例展示版式。两份文件均为赛前模板，尚无正式赛题数据。
5. AI 工具使用声明位于参考文献前。电子版从摘要开始，无身份页或目录；这部分沿用当年官方规范。

## 审核入口

先看 `preview/demo.pdf`（源码包内）或本机编译的 `build/demo.pdf`。第 1 页看题名和摘要，第 2 至 3 页看正文、三级标题、流程图、表格和公式，第 4 页看曲线图，第 6 页看附录和代码。

可填写的骨架为 `main.tex` 与 `sections/`。骨架留白来自尚未填写的内容，不能据此判断正式论文篇幅。字号和行距可在 `mathmodel.sty` 集中调整；字形来源在 `fonts.tex`。

审核重点：正文字号与行距、标题的字形和轻重、标题周围留白、图表配色。用户确认后再将样式状态改为批准；编译检查和 AI 视觉检查不替代用户审核。
