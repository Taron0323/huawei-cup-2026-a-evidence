# 论文与支撑材料交付模板

## 推荐目录

```text
submission-package/
├── paper.pdf                 # 论文 PDF
├── paper-source/             # LaTeX 或 Word 主源及必要资源
├── results/                  # Excel、CSV、JSON 和参数
├── code/                     # 运行、求解、核验和绘图代码
├── data/                     # 规则允许提交的输入或清洗数据
├── figures/                  # 图源、可编辑文件和导出图
├── ai-usage/                # 当年要求的 AI 使用详情
├── requirements.txt         # 依赖和版本
├── RUN.md                    # 从干净环境运行说明
├── VERIFICATION.md           # 验证命令和实际结果
└── MANIFEST.json             # 文件清单和来源
```

## 交付前检查

论文 PDF、LaTeX 源、结果 Excel、运行代码、必要数据、图件、AI 使用详情、依赖、运行说明、核验报告和目录清单应相互对应。结果表不能只放最终数字；至少保留导出规则、单位和日期说明。图表应从结果文件生成，正文结论应能回到结果文件。

最终组包前执行 PDF 文本和逐页渲染检查，检查字体、公式、图表、分页、空白、超链接、匿名信息和元数据。执行 `unzip -t`，检查重复路径、绝对路径、`..` 路径、隐藏文件和压缩包大小。若规则允许，从解压副本重新运行验证入口。

## 规则边界

文件名、目录层级、页数、摘要限制、Excel 数量、AI 声明、支撑材料、匿名和大小限制都可能因华为杯届次改变。模板只提供组织方式，正式参赛时必须以当年官方通知和上传系统为准。不要把本次 C 题的五个 Excel、48 页 PDF 或 CUMCM 文件名当作华为杯固定要求。
