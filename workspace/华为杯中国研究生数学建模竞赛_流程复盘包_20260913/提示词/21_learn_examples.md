# 增量学习新增范文

先运行 `.venv/bin/python tools/index_examples.py`，读取 `references/examples/QUEUE.md` 和 `manifest.json`。只处理新增、内容更新或尚无匹配学习记录的材料，不能因文件名相同就沿用旧结论。

每篇先检查提取文本完整性和页面总览，再阅读与建模和表达有关的全部主体；公式、几何图、表格等需要回到原 PDF 核对。扫描版无法可靠提取时先做 OCR 或按页阅读，并如实记录缺页或未读范围。文中身份信息和宣传内容不进入模板。

把笔记写入该论文的 `study.md`：来源页码、每问的结构、可迁移的推导和写作顺序、图表论证任务、需避开的科学或排版问题。举例时明确区分原文引用和自拟改写。获奖标签未经原始来源核验时继续保留未核实状态。

实际阅读后，才在 `study_registry.json` 中登记来源 SHA-256、读过的主体页码、检查过的页面布局及代码是否执行。无法运行的代码保持 NOT_RUN；提取文本不能标为复现。重新运行索引，让队列按记录与哈希更新。

将有用的方法合并到 `references/writing_patterns.md`，优先补充已有原则，避免堆积相似规则。若新例子与旧规则冲突，依据数学条件解释适用范围。只迁移结构和表达，不复制模型结论、身份信息或未核实的数字。
