# 逐问实现与基线

按 common.md 读取已有代码、冻结公式和参数表。先实现可解释基线，然后实现已选增量。复用 SciPy、OR-Tools、scikit-learn、statsmodels、NetworkX 等成熟库；核查 API、停止准则和求解状态。

参数集中配置并注明来源。随机种子预先列明。求解代码只产出数据，绘图代码单独读取 CSV。每个关键功能先用小算例或前 100 行检查，再跑正式数据；长任务写日志、超时与进度文件。

使用 paper/code/run_utils.py 记录输入哈希、代码哈希、参数、种子、依赖、时间、求解状态及输出哈希。不同运行使用独立目录，不能覆盖产生旧论文数字的证据。

输出代码、结果 CSV、列解释、公式对应关系、小规模核验和运行清单。求解器失败或只有可行解时明确写状态；先检查约束满足再解释目标值。
