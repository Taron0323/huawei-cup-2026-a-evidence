# 数据体检与清洗

先用 tools/data_audit.py 扫描完整数据。检查各表行列、类型、缺失模式、分布、极值、重复、主键、多表连接、时间断档、单位和编码，以及题面与实际数据的差异。单位、主键、关联和时间列来自题面或数据字典，不凭列名猜定。

将客观体检与清洗决策分开写入 paper/data_report.md 和 paper/cleaning_plan.md。对异常先说明证据，不能为提高指标直接删掉极值。训练／验证先划分，缺失填补、缩放、特征选择在训练部分拟合后应用于验证部分。

清洗输出到 paper/clean/；保存可复算代码、前后样本数、每项变换与受影响记录。无法读入或 schema 未覆盖的文件显式列出，不报告“全部正常”。

验收：原始哈希不变；样本增减有解释；字段与单位可追溯；数据泄漏风险明确关闭或记录。
