# 华为杯中国研究生数学建模竞赛流程复盘包

本包把本次 C 题从题面接收到最终提交的完整工作链整理成可复用资料，服务于下一次华为杯研究生数学建模竞赛。它包含流程复盘、迁移手册、执行清单、证据规则、提示词、论文与支撑材料模板，以及本次项目的阶段映射和资产索引。

## 使用顺序

1. 先读《华为杯迁移手册》和《版本与状态说明》，确认哪些内容必须以新一届官方通知为准。
2. 再读《下一届执行清单》，将项目目录和责任人建立起来。
3. 按《提示词使用说明》调用 `提示词/` 中的阶段提示词，并把结果写入新项目，不覆盖本包。
4. 用《团队协作与证据规则》建立结果、图表、正文和核验之间的可追溯关系。
5. 交付前按《论文与支撑材料交付模板》组包，重新核对华为杯当年规则。

## 边界

本包记录的是工作方法和本次 C 题的真实项目经验，不是华为杯官方规则。华为杯的题面、报名资格、答题时长、论文模板、AI 使用要求、文件清单、大小限制和上传平台必须在正式参赛时重新核对。历史 C 题数值仅用于理解流程，不能写入新题答案。

人工审阅、正式上传和外部服务器核验均保持真实状态。本包没有代填这些状态，也没有执行华为杯报名或上传。

## 目录

- `本次C题流程复盘.md`：按时间顺序复盘本次项目。
- `华为杯迁移手册.md`：把流程迁移到华为杯时的操作方法和边界。
- `下一届执行清单.md`：从赛前到上传前的可勾选验收项。
- `团队协作与证据规则.md`：文件、责任、证据和审阅规则。
- `提示词使用说明.md`：本包内提示词的阶段用途和使用边界。
- `论文与支撑材料交付模板.md`：论文和支撑包的通用目录。
- `本次C题阶段映射.csv`：关键阶段与经验的对应关系。
- `当前项目资产索引.md`：本次项目重要入口文件。
- `版本与状态说明.md`：本次结果的状态、证据和不可迁移项。
- `提示词/`：通用阶段、模式和 review 提示词。
- `模板/`：LaTeX、AI 声明和 Word 模板。
- `本次项目证据参考/`：本次 C 题工作法、证据入口和关键阶段记录。
- `文件清单.json`：打包后的文件、大小和校验清单。
